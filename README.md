## 🚀 Quick Start

### 1. Installation
```bash
npm install
```

### 2. Local Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5173`.

### 3. Production Build
```bash
npm run build
```
Production assets are generated in the `dist/` directory.
